# what is github ? 
  
GitHub is a web-based platform for hosting and collaborating on software projects using Git.

In simple terms:
- Git is the version-control system that tracks changes in code.
- GitHub is the online service where people store Git repositories, collaborate, review code, and manage projects.

What GitHub is used for:
- Store code in repositories
- Track changes over time
- Work together with teammates
- Open issues and bug reports
- Create pull requests for code review
- Run automation with GitHub Actions
- Host documentation, projects, and open-source software

Common GitHub features:
- Repositories: project folders for code
- Branches: parallel versions of code
- Commits: saved versions of changes
- Pull requests: propose and review changes
- Issues: track tasks, bugs, and discussions
- Actions: automate build/test/deploy workflows

How to create a GitHub account:
1. Go to https://github.com
2. Click Sign up
3. Enter your email, password, and username
4. Choose whether you want a free plan or paid plan
5. Verify your email address
6. Complete the setup steps and you’re ready to create repositories

Why GitHub matters:
- It is widely used by developers, companies, and open-source communities
- It helps teams collaborate efficiently
- It is a standard platform for software development
