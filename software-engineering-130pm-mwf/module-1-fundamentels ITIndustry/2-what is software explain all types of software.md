# What Is Software?

**Software** is a collection of instructions, data, and programs that run on a computer or another electronic device. It allows users and systems to perform tasks such as managing information, processing data, communicating, and controlling devices.

Software is different from hardware. Hardware refers to the physical parts, such as a processor, memory, keyboard, and screen. Software provides the instructions that tell the hardware what to do.

## Types of Software

Software can be classified in several ways. The following categories are commonly used in software engineering and computer education.

## 1. System Software

System software manages the computer system and provides the foundation on which other software runs. It usually operates at the operating-system or hardware level.

Examples include:

- Operating systems such as Windows, Linux, macOS, and Android
- Device drivers
- System services
- Disk-management tools
- Firmware
- Bootloaders

### Operating systems

An operating system controls the computer and provides services such as:

- Managing processes
- Allocating memory
- Managing files
- Providing user interfaces
- Controlling input and output
- Supporting hardware devices

### Device drivers

A device driver allows the operating system to communicate with a hardware device. For example, a printer driver allows the computer to send print commands to a printer.

### Firmware

Firmware is low-level software stored in a device's permanent memory. It usually controls hardware initialization and basic operation. Examples include BIOS, UEFI, and the software inside a router or mobile phone.

---

## 2. Application Software

Application software is designed to help users complete specific tasks. It is usually installed or downloaded and runs on top of an operating system.

Examples include:

- Microsoft Word
- Google Chrome
- Microsoft Excel
- WhatsApp
- Netflix
- Canva

Application software can be divided into several further categories.

### Desktop software

Desktop software runs on a personal computer and commonly provides a graphical user interface. It can be used for office work, design, media, or entertainment.

Examples:

- Word processors
- Spreadsheets
- Graphic design tools
- Video editors
- Computer games

### Mobile software

Mobile software is designed for smartphones and other mobile devices. It may be installed from an application store or downloaded as an APK file.

Examples include:

- Social media applications
- Messaging applications
- Mobile banking applications
- Navigation applications
- Mobile games

### Web software

Web software runs through a web browser and is delivered over the Internet. It may be used without installing it on the computer.

Examples include:

- Google Docs
- Online banking systems
- E-commerce websites
- Email services
- Cloud storage services

### Browser software

A web browser is software that interprets web pages and allows users to access websites. Examples include Google Chrome, Microsoft Edge, Mozilla Firefox, and Safari.

A browser may support:

- HTML
- CSS
- JavaScript
- Web APIs
- Browser extensions

---

## 3. Programming Software

Programming software is used by developers to create, edit, compile, debug, and test programs.

Examples include:

- Visual Studio Code
- Visual Studio
- Eclipse
- IntelliJ IDEA
- Notepad++
- GCC
- Java Development Kit
- Python IDLE

Programming software commonly includes:

- Text editors
- Code compilers
- Interpreters
- Debuggers
- Integrated development environments
- Version-control tools

### Compilers

A compiler translates source code into machine-readable code. It converts a high-level language such as C++ or Java into executable code.

### Interpreters

An interpreter executes source code line by line without creating a separate compiled program. Examples include Python and JavaScript interpreters.

### IDEs

An integrated development environment combines several development tools in one application. It may include a code editor, compiler, debugger, file manager, and build tools.

---

## 4. Utility Software

Utility software performs a specific task that helps users manage their computer or improve the performance of other software.

Examples include:

- Antivirus software
- Backup software
- Disk-cleanup tools
- File compression tools
- Malware scanners
- Screen recorders
- Password managers
- System monitoring tools

Utility software is often smaller and more focused than a complete application.

---

## 5. Middleware Software

Middleware software acts as a bridge between different applications, operating systems, or network services.

It can provide:

- Database access
- Communication between applications
- Authentication and authorization
- Resource management
- Application integration

Examples include:

- Application servers
- Web servers
- Database servers
- Message queues
- API gateways
- Middleware platforms such as Apache, Spring, and Microsoft .NET

Middleware is commonly used in large business systems where many applications must work together.

---

## 6. Cloud Software

Cloud software is delivered through cloud computing services and accessed over the Internet. It may be used through a browser or a dedicated application.

Examples include:

- Google Drive
- Microsoft OneDrive
- Amazon S3
- Microsoft Azure
- AWS
- Google Cloud
- Salesforce

Cloud software can provide:

- Storage
- Computing resources
- Databases
- Networking
- Applications
- Infrastructure management

Cloud software is often divided into:

- **Software as a Service (SaaS)**
- **Platform as a Service (PaaS)**
- **Infrastructure as a Service (IaaS)**

---

## 7. Embedded Software

Embedded software is installed in devices with limited resources, such as refrigerators, cars, medical devices, industrial machines, and mobile phones.

It is designed to:

- Control hardware
- Process sensor data
- Perform repeated tasks
- Operate continuously
- Use limited memory and processing power

Examples include:

- Software in a washing machine
- Firmware in a smartphone
- Navigation software in a car
- Control software in an industrial machine
- Medical-monitoring software

Embedded software is usually reliable, efficient, and designed for a specific device.

---

## 8. Firmware and Hardware Control Software

Firmware is low-level software stored inside a device. It controls the hardware and supports the device's basic operations.

Examples include:

- BIOS or UEFI on a computer
- Router firmware
- Camera firmware
- Printer firmware
- Mobile phone firmware

Firmware is different from application software because it is usually not easily updated by ordinary users and may be tightly connected to the device hardware.

---

## 9. Open-Source Software

Open-source software has source code that users can inspect, modify, and distribute. It is usually released under a license that permits these actions.

Examples include:

- Linux
- Apache
- MySQL
- PostgreSQL
- Python
- Mozilla Firefox
- LibreOffice

Open-source software may be used by individuals, businesses, or governments. It can also be modified to meet specific requirements.

### Advantages

- Users can inspect the code
- Users can modify the software
- It can be used without paying a license fee
- It can be supported by a large community

### Disadvantages

- Users may need technical knowledge to modify it
- Maintenance depends on the development community
- Some open-source software may have limited documentation

---

## 10. Commercial Software

Commercial software is produced and distributed by a company. It is usually protected by copyright and requires payment or subscription.

Examples include:

- Microsoft Office
- Adobe Creative Cloud
- AutoCAD
- Microsoft Windows
- Apple iOS

Commercial software often provides:

- Customer support
- Formal documentation
- Regular updates
- Professional training
- Commercial licensing

---

## 11. Freeware and Shareware

### Freeware

Freeware is software that is available free of charge. It may include limited features or be used for personal purposes only.

Examples include:

- LibreOffice
- GIMP
- Firefox
- VLC

### Shareware

Shareware is software that can be used without payment for a trial period or for limited functionality. Users may purchase it after testing.

Examples include trial versions of office software and antivirus programs.

---

## 12. Browser Extensions and Plugins

Browser extensions add new features to a web browser. They can change how a website looks or add tools to the browser.

Examples include:

- Ad blockers
- Password managers
- Language translation tools
- Video download extensions
- Code editors for web pages

Plugins are similar but are generally designed for a specific application or platform.

---

## 13. AI Software

AI software uses artificial intelligence techniques to perform tasks that normally require human intelligence.

Examples include:

- Voice recognition software
- Image recognition software
- Recommendation systems
- Chatbots
- Translation tools
- Computer vision systems
- Machine-learning platforms

AI software may use algorithms, models, and large datasets to identify patterns, make predictions, or generate results.

---

## 14. Database Software

Database software manages and organizes large amounts of information. It allows users and applications to create, retrieve, update, and delete data.

Examples include:

- MySQL
- PostgreSQL
- Microsoft SQL Server
- Oracle Database
- MongoDB

Database software is often part of a larger application or system. It may be installed locally or accessed through a cloud service.

---

## 15. Distributed Software

Distributed software runs across multiple computers or devices and shares resources or data. It is commonly used in networks, cloud services, and large organizations.

Examples include:

- Distributed databases
- Network file systems
- Cloud applications
- Separation of software components across servers
- Peer-to-peer applications

---

## Software Classification by Access

### Local software

Local software is installed and executed on the user's device. It does not require a continuous Internet connection.

### Web-based software

Web-based software is accessed through a web browser and requires an Internet connection.

### Cloud software

Cloud software is hosted on remote servers and accessed through the Internet. The user usually does not manage the physical server.

---

## Software Classification by Availability

- **Proprietary software:** Owned by a company and distributed under a commercial license.
- **Open-source software:** Source code is available for inspection and modification.
- **Freeware:** Available free of charge.
- **Shareware:** A trial version is provided before purchase.

Software is a set of instructions and data that enables a computer or electronic device to perform tasks. The major categories include system software, application software, programming software, utility software, middleware, cloud software, embedded software, firmware, open-source software, commercial software, and AI software.
