# What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create and structure content on the web.

## Purpose of HTML
HTML tells the browser how to display content such as:
- headings
- paragraphs
- links
- images
- lists
- tables
- forms

It is used to define the structure of a webpage, not its visual styling.

## Example
```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph in HTML.</p>
    <a href="https://example.com">Visit Example</a>
  </body>
</html>
```

## Key points
- HTML uses tags like `<h1>`, `<p>`, and `<a>`.
- Tags are enclosed in angle brackets.
- Most tags come in pairs, such as `<p>...</p>`.
- Browsers read the HTML and display the page to users.

## In simple words
HTML is like the skeleton of a webpage. It gives the page its structure, while CSS handles the design and JavaScript adds interactivity.

HTML is the foundation of every web page.
